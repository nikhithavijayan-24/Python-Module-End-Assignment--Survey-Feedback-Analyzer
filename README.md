# 📊 Survey Feedback Analyzer

A beginner-friendly Python project that analyzes customer survey feedback using basic Python programming concepts. The project focuses on collecting feedback, cleaning text data, and extracting useful insights from customer ratings and comments.

## 🎯 Project Overview

The Survey Feedback Analyzer stores customer details, feedback comments, and ratings in a Python dictionary. It processes textual feedback and summarizes key information to help understand customer responses.

## ✨ Features

- **Feedback Collection:** Add new feedback entries dynamically using user input.
- **Data Cleaning:** Remove punctuation, normalize spaces, and convert text to lowercase.
- **Word Count Analysis:** Count feedback entries containing specific words such as *good*, *poor*, and *excellent*.
- **Rating Analysis:** Calculate the average customer rating.
- **Longest Feedback:** Identify the feedback comment with the highest word count.
- **Unique Word Extraction:** Generate a list of unique words across all feedback comments.
- **Feedback Sorting:** Optionally sort feedback entries by rating from highest to lowest.

## 🛠️ Technologies Used

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Concepts:** Dictionaries, Lists, Loops, Conditional Statements, Functions, String Manipulation, `zip()`, and `sorted()`

## ⚙️ How to Run

1. Clone or download this repository.
2. Open `Survey Feedback Analyzer.ipynb` in Jupyter Notebook.
3. Run the notebook cells in sequence.
4. Enter additional feedback details when prompted.
5. View the cleaned data and generated insights.
